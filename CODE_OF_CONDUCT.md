# HaulDesk Community Code of Conduct

HaulDesk is an open-source project built for anyone who wants a clean, local-first way to organize online orders and hauls. To keep this repository constructive and welcoming for contributors and newcomers alike, all participants are expected to follow these standards in issues, pull requests, discussions, and community threads.

## Expected Behavior

- **Be respectful and constructive:** Critique code, UX, or architecture thoughtfully rather than attacking people.
- **Welcome beginners:** Many users and first-time contributors come from non-engineering backgrounds; answer questions patiently.
- **Respect privacy:** Never share another person's private server URLs, personal addresses, parcel tracking numbers, or identifying screenshots without consent.
- **Stay transparent:** Disclose AI-assisted code or external snippets when relevant so reviewers can audit edge cases carefully.

## Unacceptable Behavior

- Harassment, personal insults, slurs, or intimidation of any kind.
- Doxxing or publishing private credentials, certificates, or personal data.
- Spam, referral-link flooding, or promotional hijacking of issues and PRs.
- Deliberately submitting malicious code, dependency typosquatting, or backdoors.

## Enforcement

Maintainers reserve the right to edit, hide, or close disrespectful comments, reject pull requests, or block repeat offenders from the repository. To report a concern privately, contact the repository maintainers through GitHub (for instance, via private vulnerability/moderation reporting on the repository).
